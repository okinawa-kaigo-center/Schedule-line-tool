# スケジュール作成＆LINE送信ツール

訪問介護事業所の「スタッフ日毎スケジュール表」（Excel）を読み込み、ヘルパー一人ひとりに送る LINE 用の文面を自動で作るツールです。予定の変更を検出して差分だけを伝えたり、変更を反映した Excel を元の様式のまま書き出したりできます。

HTML ファイル 1 つで動きます。サーバー側の処理はありません。

---

## できること

### LINE 用の文面を作る

Excel を読み込むと、スタッフごとの訪問予定が文面になります。

```
本日（9/4　金）の連絡です。

8:00-8:30 山田　花子／通院乗降
11:30-12:29 沖介　太郎／生活３
14:00-17:00 沖介　花子／重訪Ⅱ

よろしくお願い致します。
```

冒頭と結びの文は自由に設定でき、翌日以降も引き継がれます。`{日付}` は Excel の日付に、`{いつ}` は「本日」「明日」などに自動で置き換わります。

### 変更を自動で検出する

「そのヘルパーに最後に送った内容」と「今の Excel」を比べ、変わった人だけを拾い出します。予定を修正して Excel を出し直し、もう一度読み込ませるだけです。

```
本日（9/4　金）の変更連絡です。

【変更のお知らせ】

■追加
14:30-15:30 山本太郎／独自

■キャンセル
16:00-17:00 沖縄　花子／障家事

──────
【変更後の予定】
（変更後の全予定）

以上、変更追加よろしいでしょうか？
```

### 手作業で予定を直す

介護ソフトに反映する前でも、画面上で予定を変えられます。

| 種類 | 内容 |
|---|---|
| 追加 | 訪問を新しく入れる |
| キャンセル | 訪問をなくす |
| 調整 | 別のヘルパーへ移す（時刻の変更も同時にできる） |
| 内容変更 | 時刻・利用者名・サービス種別を直す |

担当を移すと、元のヘルパーと移った先の両方の文面が同時にできあがります。移す相手を選ぶ画面には、その時間に空いている人が表示されます。

### 間違いに気づける

- **時間の重なり** … 同じヘルパーの予定が重なると赤い枠で警告
- **同じ利用者の重なり** … 別のヘルパーに同時刻で入っていると紫の枠で警告。2 人体制や同行のときは「同行」に設定でき、文面に「（〇〇 と同行）」が入る
- **配車の重複** … 同じ車両を 2 人以上に割り当てると赤く表示

### Excel を書き出す

変更を反映した Excel を、**元の様式のまま**書き出せます。元ファイルの XML を直接書き換える方式なので、触っていない部分は 1 バイトも変わりません。罫線・塗り・列幅・結合セルがそのまま残ります。

書き出す Excel には次のものも入ります。

- **配車** … スタッフ名の右に大きく表示（D 列〜O 列を結合）
- **備考** … 予定表の右に枠を作って表示（GN 列〜HG 列、12 行ごと）
- **蛍光ペン** … 同じ利用者が同時刻に入っている訪問の利用者名を黄色で強調。同行に設定したものには赤い「同」が付く

## 使い方

### 1. 置き場所を用意する

**https のページとして開く必要があります。** ファイルをダブルクリックして開くと、送信の記録が保存できず、変更の検出が働きません。

- [Netlify Drop](https://app.netlify.com/drop) … フォルダをドラッグするだけ。アカウントを作れば継続して使えます
- Firebase Hosting … `firebase deploy` で公開

ファイル名を `index.html` にしてフォルダに入れ、そのフォルダごと置いてください。

### 2. 毎日の流れ

1. 介護ソフトから 1 日分の Excel を書き出す
2. ツールを開いて Excel を選ぶ
3. スタッフごとに「送る」（スマホ）または「コピー」（パソコン）を押す
4. 予定が変わったら、Excel を出し直してもう一度読み込ませる
5. 必要なら「変更後のExcel（元の形式）」で書き出す

配車や送信対象のチェックは日付をまたいで残るので、変わったときだけ直せば済みます。

## 前提としている Excel の様式

「スタッフ日毎スケジュール表（5 分単位）」の書き出しに合わせています。

| 項目 | 位置 |
|---|---|
| 日付 | 1 行目の「令和◯年◯月◯日～令和◯年◯月◯日」 |
| スタッフ名 | C 列 |
| 訪問の時刻 | スタッフ行の D 列以降 |
| 利用者名 | その 1 行下 |
| サービス種別 | その 2 行下 |
| 時間軸 | D 列 = 6:00、以降 **5 分 = 1 列** |

1 スタッフあたり 4 行で 1 ブロックです。`担会（　）` の枠（6:00-6:01）は予定として扱いません。

**期間が 2 日以上の Excel は読み込みません。** 同じスタッフが複数回現れて予定が上書きされるため、エラーを表示して止まります。

## データの扱い

**利用者の情報がサーバーに送られることはありません。** Excel の読み取りも文面の生成も Excel の書き出しも、すべてブラウザの中だけで完結します。

ツール本体には利用者名も訪問時刻も含まれていないため、URL が公開されていても問題ありません。

設定と記録は端末の localStorage に保存されます。

| キー | 内容 | 保持 |
|---|---|---|
| `base_YYYY-MM-DD` | 各ヘルパーに最後に送った内容 | 60 日 |
| `man_YYYY-MM-DD` | 手作業の追加・キャンセル・担当変更・内容変更 | 60 日 |
| `note_YYYY-MM-DD` | Excel に入れる備考 | 60 日 |
| `pair_YYYY-MM-DD` | 同行の設定 | 60 日 |
| `edit_YYYY-MM-DD` | 手直しした文面 | 60 日 |
| `cars` / `carlist` | 配車と車両の候補 | 無期限 |
| `skip` | 送信対象から外したスタッフ | 無期限 |
| `tpl` | 冒頭と結びの定型文 | 無期限 |
| `staffnames` | 前回のスタッフ名（最初の画面の配車設定用） | 無期限 |

日付を含むキーは、読み込みのたびに 60 日より古いものが自動で削除されます。

**記録は端末とブラウザごとに別々です。** 別の端末で開くと全員が「未送信」に見えます。

## 技術的なこと

依存しているのは 2 つだけです。どちらも CDN から読み込みます。

- [SheetJS (xlsx) 0.18.5](https://cdnjs.com/libraries/xlsx) … Excel の読み取り
- [JSZip 3.10.1](https://cdnjs.com/libraries/jszip) … Excel の書き出し（xlsx を zip として直接操作）

### 書き出しの方式について

当初 SheetJS で書き出していましたが、**読み書きするだけで塗り 4511 個と罫線 8289 個をすべて失う**ことが分かりました。次に ExcelJS を試したところ、元ファイルの `<b val="0">`（太字でない）を太字と誤読し、**シート全体が太字・斜体・取り消し線**になりました。

最終的に、xlsx を zip として開き、`xl/worksheets/sheet1.xml` と `xl/styles.xml` を直接書き換える方式にしています。書式は新しく作らず、元ファイルの中にある書式をそのまま借ります。

実装時に踏んだ落とし穴を記録しておきます。

- 要素は名前空間付きで作る。`createElementNS(null, ...)` だとブラウザが `xmlns=""` を付けて Excel に無視される
- `<rPr>` の子要素の順序は `rFont → charset → family → b → color → sz`。順序が違うと Excel が書式ごと落とす
- **結合セルは、範囲内の全セルが同じ書式でなければ罫線が正しく描かれない**
- 訪問の帯は 4 行で 1 組（4 行目は高さ 6pt の仕切り行）
- Excel はセルの書式を共有しているため、書き換える前にセルごとに複製しないと無関係なセルまで変わる

### 対応環境

| 環境 | 送信ボタン |
|---|---|
| iPhone / iPad / Android | 共有メニューが開く |
| Windows / Mac / Linux（Chrome・Firefox・Edge） | クリップボードにコピー |

判定は端末の種類で行っています。共有機能の有無だけで判定すると、Windows の Chrome もスマホ扱いになってしまうためです。

## 制限

- **介護ソフトへは書き戻せません。** ソフト側の修正は手作業です
- **時間が重なる訪問は、元の様式の Excel では片方が消えます。** 1 つのマスに 1 件しか置けないためです。書き出し時に警告が出ます
- 備考の枠は 7 件までが表の高さに収まります
- 配車の枠は 6:00〜7:00 の位置に入ります。この時間帯に訪問があると重なります
- 文面を手直しすると、その後に予定を変えても文面には反映されません（「元に戻す」で解除できます）

---

## 保守について

介護ソフトの書き出し様式が変わると動かなくなります。そのときは、新しい様式の Excel を用意して読み取り部分を調整する必要があります。

見た目の調整（枠の位置や大きさ、罫線）は、**そうなっている Excel を 1 つ用意して、そこから書式を読み取る**方法を取っています。位置や寸法を推測するより確実です。
